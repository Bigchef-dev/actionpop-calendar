# Action Populaire Contracts

The upstream contracts are split by source responsibility:

- [Groups and catalogue](action-populaire-groups.md): group discovery, active status,
  coordinates, and catalogue synchronization.
- [Events](action-populaire-events.md): event detail, group event lists, pagination,
  payload validation, mapping, and failure classification.

The worker orchestration contract is documented separately in
[worker.md](worker.md).
